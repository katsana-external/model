# 8.x Branch Setup Instructions

This file contains instructions for setting up the 8.x branch with Laravel 10 and PHP 8.2 support.

## Manual Steps Required After Merge

1. Create the 8.x branch from the 7.x branch:
   ```bash
   git checkout -b 8.x origin/7.x
   ```

2. Cherry-pick the commit with Laravel 10 upgrades:
   ```bash
   git cherry-pick 8897e00
   ```

3. Push the new 8.x branch:
   ```bash
   git push origin 8.x
   ```
